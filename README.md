# Week 3 Assignment on Conditions and Loops

This repository contains my Week 3 Python assignment on conditions and loops.

* `grade_reporter.py` - Uses a `for` loop and `if/elif/else` conditions to assign grades, count passes and failures, and calculate the average.
* `bug_hunt.py` - Fixes three bugs in a `while` loop program that calculates the sum from 1 to 5.
* `screenshots/` - Contains screenshots showing both programs running successfully.

The hardest bug to find was the `count < 5` condition because it did not produce an error message. I knew something was wrong because the program ran but produced the wrong answer instead of the required 15.
